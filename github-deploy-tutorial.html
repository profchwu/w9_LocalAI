0 準備工作

跟著本教學，你只需要一台電腦與網路連線（用來下載 Git 與註冊 GitHub）。全部操作都在「終端機 / 命令列」完成，不需要安裝額外的桌面軟體。

🪟 Windows

安裝 Git for Windows，隨附 Git Bash 終端機。

🍎 macOS

透過 Homebrew 安裝，或使用 Xcode Command Line Tools。

🐧 Linux

使用套件管理器（apt / yum / dnf）安裝 git。

💡 提示： 如果你從來沒用過終端機，不用擔心，本教學會把每一個指令都列出來，複製貼上就能執行。

1 步驟 1：安裝 Git

Git 是版本控制工具，讓你紀錄程式碼變更，並能上傳到 GitHub。

Windows 安裝方式

  1. 前往 git-scm.com 下載 Git for Windows。
  2. 執行安裝程式，大部分選項保持預設即可。
  3. 安裝完成後，在開始選單找到「Git Bash」並開啟。

macOS 安裝方式

$/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
$brew install git

若你沒有 Homebrew，也可直接在終端機輸入 git，系統會提示安裝 Xcode Command Line Tools。

驗證是否安裝成功

$git --version

若看到類似 git version 2.45.0 的訊息，即表示安裝成功。

終端機驗證 Git 版本範例

2 步驟 2：建立 GitHub 帳號

  1. 開啟瀏覽器，前往 github.com。
  2. 點擊右上角「Sign up」註冊。
  3. 輸入電子郵件、設定密碼、建立使用者名稱（Username）。
  4. 完成圖形驗證與電子郵件驗證。
⚠️ 重要： 註冊時設定的使用者名稱會出現在你的網站網址中（例如 username.github.io），建議選擇簡單好記的英文名稱。
GitHub 註冊頁面簡化示意圖

3 步驟 3：設定 Git 身分

在上傳程式碼前，請告訴 Git 誰是提交者，這會出現在每一次的紀錄中。

$git config --global user.name "你的名字"
$git config --global user.email "你的 email"

請將 你的名字 與 你的 email 替換成你在 GitHub 註冊時使用的資訊。

$git config --global --list

用來確認設定已生效。

💡 提示： 如果你不想每次推程式碼都輸入密碼，可設定 SSH 金鑰（進階選項，本教學以 HTTPS 方式示範即可跑通）。

4 步驟 4：建立本地專案

先在電腦上建立一個簡單網站資料夾，並初始化 Git 儲存庫。

$mkdir my-website
$cd my-website
$git init

建立網頁檔案

在 my-website 資料夾中建立 index.html，內容如下：

<!DOCTYPE html>
<html lang="zh-TW">
<head>
  <meta charset="UTF-8">
  <title>我的第一個 GitHub 網站</title>
</head>
<body>
  <h1>你好，GitHub！</h1>
  <p>這是我第一次透過 GitHub Pages 上架的網頁。</p>
</body>
</html>
✅ 完成： 你現在有一個本地 Git 專案，裡面有一個網頁檔案。

5 步驟 5：在 GitHub 建立遠端 Repository

  1. 登入 GitHub，點擊右上角你的大頭照 → 「Your repositories」。
  2. 點擊綠色「New」按鈕建立新 repository。
  3. Repository name 輸入 my-website（或你喜歡的名稱）。
  4. 選擇「Public」。（免費帳號也可選 Private，但 Pages 建議用 Public。）
  5. 不要勾選「Add a README file」，以免與本地檔案衝突。
  6. 點擊「Create repository」。

建立完成後，GitHub 會顯示一個網址，類似：

$https://github.com/你的使用者名稱/my-website.git
GitHub 建立新 Repository 頁面示意圖

6 步驟 6：將程式碼推上 GitHub

在終端機中，回到 my-website 資料夾，依序執行以下指令：

🔗 連結本地與遠端：
將 你的使用者名稱 替換成你的 GitHub 帳號名。
$git remote add origin https://github.com/你的使用者名稱/my-website.git
📦 加入檔案並提交：
$git add .
$git commit -m "初始提交：加入 index.html"
🌿 設定主分支為 main：
$git branch -M main
🚀 推送到 GitHub：
$git push -u origin main

若系統彈出視窗要求輸入 GitHub 帳號與密碼，請輸入註冊時的資訊。（部分環境會要求使用 Personal Access Token，而非直接密碼。）

✅ 完成： 刷新 GitHub Repository 頁面，你應該能看到 index.html 已經上傳。
從本地推送程式碼到 GitHub 流程示意圖

7 步驟 7：啟用 GitHub Pages 上架

GitHub Pages 可免費將你的 Repository 當成網站託管，產出類似 https://你的使用者名稱.github.io/my-website/ 的網址。

  1. 進入你的 Repository 頁面，點選上方選單的 Settings。
  2. 在左側邊欄點選 Pages。
  3. 在「Build and deployment」區塊，Branch 選擇 main，Folder 選擇 (root)。
  4. 點擊 Save。
  5. 等候 1~2 分鐘，頁面會顯示綠色網址，點擊即可開啟你的網站。
🎉 上架成功！ 你現在可以將網址分享給任何人瀏覽。

8 常見問題與除錯

問題可能原因解決方式
git 不是內部或外部命令Git 未安裝或未加入 PATH重新安裝 Git，或重新開啟終端機
推送時要求輸入帳號密碼失敗GitHub 已停用帳號密碼驗證改用 Personal Access Token 或設定 SSH 金鑰
Pages 網址顯示 404尚未完成部署，或分支設定錯誤在 Settings → Pages 確認分支為 main，等候幾分鐘
repository 名稱與本地資料夾不同遠端網址輸入錯誤執行 git remote set-url origin ... 修正
💡 提示： 如果你之後修改了 index.html，只需執行 git add .、git commit -m "更新內容"、git push，網站會自動更新。
